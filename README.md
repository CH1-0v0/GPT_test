# 조항 카드 검색 웹페이지

## 실행 방법
브라우저의 로컬 파일(file://) 보안 정책 때문에 `fetch()`가 JSON을 읽지 못할 수 있습니다.
이 폴더에서 간단한 로컬 서버를 실행하세요.

```bash
python -m http.server 8000
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8000
```

## 포함 기능
- `조항데이터.json`을 `fetch()`로 읽어 조 번호, 제목, 본문 요약 카드 표시
- 제목/본문 실시간 키워드 검색
- `결과 N건` 표시
- 본문 펼치기/접기
- 첨부 카드뉴스 이미지 4장 `<img>` 태그로 직접 노출
